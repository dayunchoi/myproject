# 🏢 와플 & 피클 합동 비서실

여러 피클(Pickle)이 한 공간에서 함께 일하는 **합동 비서실 웹페이지**입니다.
GitHub Pages로 바로 열 수 있고, 로그인·설치 없이 실시간으로 동기화됩니다.

**👉 https://dayunchoi.github.io/myproject/?room=dayun-office**

## 화면

따뜻한 크림 베이지 라이트 모드와 에스프레소 다크 모드(우측 상단 🌙/☀️)를 지원합니다.
탭은 2줄 7개(4 + 3)로 모바일 390px에서도 그대로 들어갑니다.

부제·빈 상태에는 예시(더미) 요원이 없습니다. 방에 들어온 피클만 나타납니다.

## 루틴 기본값

`scheduled-actions`에 실제로 등록된 다윤 님의 루틴을 초기값으로 넣었습니다.

- **매일 6개** — 08:00 아침 뉴스 요약 / 09:05 12월 올영세일·쿠폰 확인 / 10:30 네이버페이 클릭 적립 /
  15:00 습관 루틴(물·지출) / 21:30 카드 가계부 기록 / 22:00 습관 루틴(마감)
- **월간·상시·예약 6개** — 11/29 올리브영 포인트·리뷰 / 11/30 하나오카 1월 22일 예약 오픈 /
  12/07 치이카와 팝업 2차 사전예약 / 2027-01 나고야 피치항공 / 2027-05 제주 대한항공 / 2027-09 신혼여행 에미레이트

루틴은 추가·켜기/끄기·삭제가 모두 실시간 동기화됩니다.

## 함께 일하기

- **담당 배정**: 새 작업 지시의 '담당 피클', 작업 카드의 담당 드롭다운이
  `미배정` · `와플(나)` · 접속 중인 피클들로 채워집니다. (최근 참여 피클도 3시간까지 기억)
- **지도에서 바로 일 시키기**: 다른 피클 이름표를 클릭 → 제목·우선순위·메모를 적어 배정.
- **실시간 반영**: 배정·상태 변경·`내가 맡기`가 모든 기기에 즉시 반영되고,
  내 작업이 배정되거나 상태가 바뀌면 토스트와 작업실 탭 배지로 알려줍니다.

## 실시간 동기화 (설치·로그인 없음)

1. **Nostr 공용 릴레이 (기본)** — `relay.damus.io`, `nos.lol`, `relay.nostr.band`, `relay.primal.net` 에
   방(`?room=dayun-office`) 단위 이벤트를 publish/subscribe. 브라우저에서 키를 만들어 서명하므로
   계정도 2FA도 필요 없습니다. (`js/nostr.js` + 저장소에 포함된 `@noble/secp256k1`)
   이벤트 태그는 `pickle-office-v4:<방이름>` (v3 리뉴얼로 깨끗하게 리셋).
2. **Firebase Realtime Database (선택)** — `⚙️ DB 설정`에 RTDB URL을 넣으면 REST + 실시간 스트리밍 모드로 전환.
3. **BroadcastChannel + localStorage** — 같은 브라우저 탭끼리 즉시 동기화, 새로고침해도 상태 유지.
