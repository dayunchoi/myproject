# 🏢 와플 & 피클 합동 비서실

여러 피클(Pickle)이 한 공간에서 함께 일하는 **합동 비서실 웹페이지**입니다.
GitHub Pages로 바로 열 수 있고, 로그인·설치 없이 실시간으로 동기화됩니다.

**👉 https://dayunchoi.github.io/myproject/**

## 방

| 탭 | 내용 |
| --- | --- |
| 🗺️ 오피스 맵 | 탑다운 2D 오피스. 실제로 접속한 피클만 보이고, 공간을 클릭하면 내 피클이 이동합니다. 다른 피클(또는 왼쪽 '접속 중인 요원' 목록)을 클릭하면 그 피클에게 바로 일을 맡길 수 있습니다. |
| 💬 회의실 | 안건 · 실시간 채팅 · 결정사항 체크리스트 |
| 🛠️ 작업실 | 칸반 보드(대기/진행/완료) · 새 작업 지시 · 담당 피클 배정 · 드래그 이동 |

예시(더미) 요원·채팅·작업은 없습니다. 방에 들어온 피클만 지도와 명단에 나타나고,
아무도 없을 때는 초대 안내 문구가 보입니다.

## 함께 일하기

- **담당 배정**: 새 작업 지시의 '담당 피클', 작업 카드의 '담당 피클 변경' 드롭다운이
  `미배정` · `와플(나)` · 접속 중인 피클들로 자동 채워집니다. (최근 참여한 피클도 3시간까지 기억)
- **지도에서 바로 일 시키기**: 다른 피클 캐릭터나 왼쪽 명단을 클릭 → 제목·우선순위·메모를 적어 배정.
- **실시간 반영**: 배정·상태 변경·`내가 맡기`가 모든 기기에 즉시 반영되고,
  내 작업이 배정되거나 상태가 바뀌면 토스트와 작업실 탭 배지로 알려줍니다.
- **말풍선**: 각 피클이 `진행 중`으로 맡은 작업이 지도 말풍선에 실시간으로 표시됩니다.

## 실시간 동기화 (설치·로그인 없음)

1. **Nostr 공용 릴레이 (기본)** — `relay.damus.io`, `nos.lol`, `relay.nostr.band`, `relay.primal.net` 에
   방(`?room=dayun-office`) 단위 이벤트를 publish/subscribe. 브라우저에서 키를 만들어 서명하므로
   계정도 2FA도 필요 없습니다. (`js/nostr.js` + 저장소에 포함된 `@noble/secp256k1`)
   이벤트 태그는 `pickle-office-v2:<방이름>` — 예전 테스트 이벤트가 섞이지 않도록 버전 prefix를 올렸고,
   주소의 `?room=` 값은 그대로입니다.
2. **Firebase Realtime Database (선택)** — `⚙️ DB 설정`에 RTDB URL을 넣으면 REST + 실시간 스트리밍 모드로 전환.
3. **BroadcastChannel + localStorage** — 같은 브라우저 탭끼리 즉시 동기화, 새로고침해도 상태 유지.

## 초대

`🔗 초대 링크 복사` 또는 주소 뒤에 `?room=방이름` 을 붙여 공유하면 같은 방으로 이어집니다.

## 내 피클 꾸미기

우측 상단 아바타 → 이름, 한글 자음 1글자, 색상, 상태 메시지 변경. 저장하면 다른 기기에도 반영됩니다.

## 배포 메모

GitHub Pages 소스는 **`gh-pages` 브랜치**입니다. (저장소 Settings → Pages에서 확인)
수정 후 배포:

```bash
git push origin main
git push -f origin main:gh-pages
```

Pages 소스를 `main` / root 로 바꾸면 `gh-pages` 푸시 없이도 자동 배포됩니다.
